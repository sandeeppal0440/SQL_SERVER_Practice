# SQL_SERVER_Practice
This repository contains my hands-on **SQL practice using Microsoft SQL Server (T-SQL)**, covering concepts from basic to advanced levels. It includes practical queries, exercises, and real-world problem-solving scenarios designed to strengthen my SQL, data analysis, and database development skills.

### SQL Dialect

* **Microsoft SQL Server — T-SQL (Transact-SQL)**

### Topics Covered

* **SQL Fundamentals:** Database concepts, tables, data types, `SELECT`, `DISTINCT`, `WHERE`, `ORDER BY`, `TOP`, aliases, and filtering.
* **Data Manipulation:** `INSERT`, `UPDATE`, `DELETE`, `TRUNCATE`, and handling NULL values.
* **Operators & Conditional Logic:** Comparison, logical, arithmetic, `IN`, `BETWEEN`, `LIKE`, `IS NULL`, `CASE`, and conditional expressions.
* **Aggregate Functions:** `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `GROUP BY`, and `HAVING`.
* **Joins:** `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL OUTER JOIN`, `CROSS JOIN`, and `SELF JOIN`.
* **Set Operations:** `UNION`, `UNION ALL`, `INTERSECT`, and `EXCEPT`.
* **Subqueries:** Scalar, multi-row, correlated, nested, and inline subqueries.
* **CTEs:** Standalone, nested, and recursive Common Table Expressions.
* **Window Functions:** `ROW_NUMBER`, `RANK`, `DENSE_RANK`, `NTILE`, `LEAD`, `LAG`, and aggregate window functions using `PARTITION BY` and `ORDER BY`.
* **String, Date & Conversion Functions:** String manipulation, date calculations, formatting, `CAST`, `CONVERT`, and other commonly used T-SQL functions.
* **Advanced SQL:** Views, temporary tables, stored procedures, user-defined functions, triggers, error handling, and dynamic SQL.
* **Database Concepts:** Primary keys, foreign keys, constraints, indexes, relationships, normalization, and database objects.
* **Data Analysis Problems:** Sales analysis, customer segmentation, ranking, running totals, top-N analysis, duplicate detection, trend analysis, and year-over-year comparisons.
* **Query Optimization:** Query execution concepts, filtering strategies, joins, indexing concepts, and writing efficient SQL queries.

### Objective

The purpose of this repository is to document my **SQL learning journey from basic to advanced T-SQL** through consistent hands-on practice, practical exercises, and real-world data analysis problems.
